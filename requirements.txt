# Persian RTL Lawyer Personal Portfolio Website
## Complete Implementation Requirements for a Coding Agent

## 1. Project Overview

Build a premium, modern, single-page personal portfolio website for a Persian-speaking lawyer.

The website must be:
- Fully Persian
- Fully RTL (right-to-left)
- Responsive on mobile, tablet, laptop, and large desktop screens
- Premium, minimal, elegant, and professional
- Designed as a personal brand / attorney portfolio, not as a generic law-firm template
- Single-page only
- Fast and SEO-friendly
- Accessible
- Production-ready
- Easy to customize later

The final website should communicate:
- Trust
- Professional authority
- Experience
- Privacy/confidentiality
- Personal attention
- Premium positioning

Do NOT use clichéd visual design such as large scales of justice, gavels, courthouse stock photos, or overly decorative legal imagery.

Use a real lawyer portrait as the primary visual asset. If no real photo is available, use a clearly marked placeholder that can easily be replaced.

- RTL

# 29. Forms / Backend

Frontend form must be production-ready but backend implementation should be separated.

Create a clean abstraction such as:

submitConsultationRequest()

so that a real API or email provider can be connected later.

Do not:
- put email credentials in frontend
- put API secrets in frontend
- expose private environment variables

If a backend is implemented:
- validate input server-side
- sanitize input
- rate-limit submissions
- protect against spam
- provide proper error handling

For the initial version, a mock submission handler is acceptable if clearly documented.
